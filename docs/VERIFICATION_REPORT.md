## Реальные причины ограничений

- Нет падающих upstream unit tests или официальных verify/build/sim checks.
- Найденные semantic gaps не обнаруживаются существующими upstream tests; отражены в RULES_ANALYSIS и наших characterization tests.
- Нет полного referee implementation/архива, поэтому end-to-end registration ingestion, archived signatures ordering, Hyperliquid fetcher и live state root не проверены.
- Signed seed проверен криптографически, но close-1 launch trust anchor не установлен; это ограничение authority, а не провал SHA-256/Ed25519.
- Путь C:\works не подготовлен из-за OS access denial; готовая копия лежит в outputs. Никакой системный ACL или elevation не менялся.
- Однократная вспомогательная inline-команда анализа JSON дала SyntaxError из-за shell quoting; итоговый подсчёт выполнен сохранённым Python verification script. Она не участвовала в official checks и не меняла данные.
- Read-only попытка посмотреть процесс через Win32_Process была отклонена ОС; проверка завершения использовала exit code job и results file, а не отсутствие процесса.
